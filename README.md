## Tech Stack

- **HTML5**: Semantic markup, Open Graph metadata, accessible landmarks, and ARIA attributes.
- **Vanilla CSS**: Custom properties (design tokens), responsive CSS Grid & Flexbox, fluid typography (`clamp()`), and CSS-only abstract project visualizations.
- **Vanilla JavaScript (ES6+)**:
  - Canvas particle network background with `requestAnimationFrame` and visibility pausing.
  - `IntersectionObserver` for scroll-triggered reveal animations and active navigation highlighting.
  - Dynamic GitHub REST API integration for public repository display.
  - Full support for `prefers-reduced-motion`.

## Local Development

The site is built with vanilla web technologies and requires no build step or package manager.

### Running Locally

You can serve the project with any local HTTP server:

**Using Python:**
```bash
python -m http.server 3000
```

**Using Node.js:**
```bash
npx serve . -l 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
